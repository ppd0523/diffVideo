# 0.3.0 검증 기록

2026-09-04, 현재 Windows 11 x64 시스템에서 실행했다.

- Release 빌드: 경고 0, 오류 0
- 일반 단위/FFmpeg 통합 테스트: 27개 통과
- 10분 1920×1080 30fps 출력 연속 2회: 통과
- WPF GUI 진단: 15개 항목 통과
  - MP3 1ms 정렬, 로딩 상태 표시, 개별 플레이어 진행
  - 재생 중 편집 잠금 및 내보내기 활성화
  - 일시정지, 1프레임 버튼, 지정 시작점으로 정지
  - 드래그 임시 상태, 취소 복원, 드롭 확정 및 재생 상태 유지
  - 로딩 중 일시정지 후 자동 재개 방지
  - 재생 중 내보내기, 내보내기 중 편집, 취소 후 `.part` 정리
  - 출력 끝에서 마지막 프레임으로 일시정지
- 원본 디코더 대체 경로: 강제 선택한 H.264 영상 두 개의 재생 진행 확인
- 실제 HEVC 320×192 30fps 4초 입력: Windows 코덱 없이 원본 디코더로 자동 대체,
  다른 Windows 플레이어와 혼합 재생, 영상 종료 후에도 통합 타임라인 진행 확인
- 회전 메타데이터 90도인 H.264 1920×1080 4초 입력: 원본 디코더 재생 및 종료 후 유지 확인
- 자원 관찰 결과: [리소스 비교](RESOURCE-COMPARISON.md)

GUI 검사는 `build/Test-PlayerPreview.ps1 -ChecksOnly`로 재현한다.
로그와 화면 캡처는 `artifacts/preview-validation/checks.json` 및 `checks.png`에 있다.
HEVC와 회전 입력 결과는 `hevc-check.json`, `rotated-check.json`에 있다.
이 기록은 모든 코덱 프로파일·VFR 입력·HDR 디스플레이 조합이나 물리적 스피커/모니터
지연의 계측을 의미하지 않는다. 프리뷰의 색감과 세부 화질 차이는 허용한 사양이다.

검증 중 발견한 취소/프로세스 종료 경합은 직접 생성한 FFmpeg 프로세스만 종료하고
종료 중 발생하는 Win32 예외가 취소 콜백 밖으로 전파되지 않도록 보강한 뒤 재확인했다.
리소스 감소율을 맞추기 위한 성능 수정·재측정은 수행하지 않았다.
