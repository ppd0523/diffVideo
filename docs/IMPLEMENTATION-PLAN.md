# DiffVideo 확정 구현 계획

## 목표와 범위

Windows 11 x64에서 MP4 영상 두 개와 선택적인 MP3 한 개를 사용자 지정
캔버스에 배치하고, 시간 오프셋·고정 ROI·오디오 믹스를 적용해 H.264/AAC
MP4 한 개로 내보낸다. 배포물은 설치 과정이 없는 portable 폴더와 ZIP이다.

지원 입력은 MP4 컨테이너의 H.264/HEVC 영상과 AAC 오디오, 별도 MP3다.
미디어 분석과 합성 계층은 확장 가능한 모델로 분리해 추후 다른 컨테이너나
코덱을 추가할 수 있게 한다.

## 확정 동작

- 영상 1·2는 서로 독립적인 시작 시각을 갖는다.
- 영상 시작 시각과 재생 위치·시작 마커는 출력 프레임 격자에 정렬하며,
  MP3 시작 시각은 1ms 격자에 정렬한다.
- 시작 전에는 해당 영상의 첫 프레임, 종료 후에는 마지막 프레임을 유지한다.
- 캔버스에서 영상이 차지하지 않는 부분만 검은색으로 출력한다.
- 출력 종료 시각은 사용자가 직접 정한다.
- 영상별 고정 ROI, 위치, 크기, Fit/Fill/늘이기, 레이어 순서를 제공한다.
- 움직이는 피사체 추적, ROI 키프레임, 투명도는 범위에서 제외한다.
- 두 영상 오디오와 MP3는 각각 포함 여부, 시작 시각, 0~200% 볼륨을 갖는다.
- MP3 기본 볼륨은 30%이며 반복하지 않는다.
- 오디오는 48kHz 스테레오로 믹스하고 짧은 페이드와 항상 켜진 리미터를 적용한다.
- 타임라인 미리보기와 최종 출력은 같은 오디오 필터 그래프를 사용한다.
- 재생·일시정지·정지를 분리한다. 정지는 사용자가 지정한 재생 시작점으로
  돌아가며, 일시정지는 현재 위치를 유지하고, 출력 끝에서는 마지막 프레임에
  일시정지한다. 끝에서 다시 재생하면 지정 시작점부터 시작한다.
- 프리뷰는 독립된 두 영상 플레이어를 화면 캔버스에 배치한다. ROI·Fit/Fill·
  크기·위치·레이어는 화면 그리기로 반영하며, FFmpeg 영상 합성은 내보내기에만
  사용한다. Windows 코덱이 없거나 회전 메타데이터가 있는 원본은 포함된
  FFmpeg로 해당 영상만 디코딩한다. 별도 프록시 동영상은 생성하지 않는다.
- 정지·일시정지 중에는 재생 헤드와 클립을 드래그할 수 있다. 클립은 드래그
  중 모델을 변경하지 않고 위치 표시와 최대 초당 10회 최신 원본 프레임 탐색만
  갱신한 뒤, 드롭할 때 한 번만 확정한다. Escape와 캡처 손실은 변경을 취소한다.
- 프리뷰 오디오는 두 영상의 오디오와 MP3를 단일 믹서로 재생한다. 장치에서
  재생된 오디오 샘플 수를 공통 시계로 사용하고 영상 플레이어의 자체 소리는 끈다.
- 영상·오디오 버퍼가 지연되면 공통 시계와 재생을 멈추고 마지막 화면 위에
  로딩 표시를 띄운다. 준비가 끝나면 재개하되, 사용자의 일시정지·정지가 우선한다.
- 프리뷰는 시간·ROI·배치 확인용이며 색감·HDR 밝기·세부 화질 차이를 허용한다.
- 재생 중에는 파일 입력과 합성 설정 및 타임라인 편집을 잠그되 내보내기는
  허용한다. 내보내기는 클릭 시점의 불변 합성 스냅샷으로 백그라운드에서
  진행하며, 활성 작업 한 개만 허용하고 취소할 수 있다.
- 내보내기 중 종료를 요청하면 기본값 `아니요`인 확인 창을 표시하고, 종료를
  선택한 경우 작업 취소와 `.part` 정리를 기다린 뒤 닫는다.
- 캔버스는 16×16~3840×2160의 짝수 크기, 출력은 24/25/30/50/60fps다.
- HDR 입력은 SDR BT.709로 톤 매핑하고 회전 메타데이터를 반영한다.
- 내보내기는 AMD AMF를 우선 사용하고 Media Foundation으로 자동 대체한다.
- 결과는 임시 `.part`에 기록한 뒤 성공했을 때만 최종 파일로 이동한다.

## 구조

- `DiffVideo.Core`: 합성 모델, 규칙, 검증
- `DiffVideo.Infrastructure`: ffprobe 분석, FFmpeg 필터/명령 생성, 미리보기와 내보내기
- `DiffVideo.App`: WPF GUI, 드래그앤드롭, 캔버스·ROI·타임라인 상호작용
- `DiffVideo.Core.Tests`: 규칙·명령 생성·실제 FFmpeg 통합 테스트

앱은 FFmpeg 라이브러리에 링크하지 않고 별도 `ffmpeg.exe`와 `ffprobe.exe`를
하위 프로세스로 실행한다. portable 앱은 self-contained .NET 단일 실행 파일이며,
두 FFmpeg 실행 파일은 같은 폴더에 둔다.

## 수용 기준

- 출력 길이 오차: 1프레임 이하
- 오디오 시작 동기 오차: 10ms 이하
- ROI와 캔버스 배치 오차: 1픽셀 이하
- 정상 재생 A/V 동기 오차 목표: 50ms 이하, 일시정지·재개 위치 오차: 1프레임 이하
- 재생 헤드·클립 드래그 탐색: 최대 초당 10회, 드롭·드래그 종료 후 원본 정지 프레임
- 연속 프레임 버튼 입력: 최신 요청 우선, 마지막 입력 약 150ms 후 정확한 프레임
- 내보내기 병행 중 프록시 프레임 드롭은 허용하되 UI 입력은 계속 응답
- 10분 1080p30 합성: 연속 2회 성공
- 취소·실패 시 `.part` 파일 미잔존
- 4K60 내보내기 지원(실시간 미리보기 성능은 보장하지 않음)
- 리소스는 동일 입력에서 기존 방식과 비교 측정만 한다. 감소 목표·통과 기준은
  두지 않으며, 감소 폭을 이유로 성능 튜닝을 반복하지 않는다.

## 배포와 공개

소스는 MIT 라이선스로 공개한다. FFmpeg는 `libx264`·`libx265`가 비활성화된
고정 LGPL 빌드를 사용하며 버전, 소스 리비전, 빌드 스크립트와 해시를 기록한다.
NAudio는 MIT 라이선스 원문을 함께 배포한다. GitHub Actions와 로컬 PowerShell
스크립트가 동일한 테스트 및 portable 패키지를 생성한다.
