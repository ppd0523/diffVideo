# UI 디자인 반영

## 0.4.0 — DiffVideo 명칭과 조정 가능한 ROI 팝업

표시명·실행 파일·솔루션·프로젝트·코드 네임스페이스·빌드·문서를 DiffVideo로 통일했습니다.
기존 작업 폴더와 이전 배포본은 유지하며 새 portable 패키지는 `DiffVideo-0.4.0-win-x64`입니다.
진단 로그는 임시 폴더의 `DiffVideo/crash.log`, 개발용 FFmpeg 경로 변수는
`DIFFVIDEO_FFMPEG_BIN`입니다. 외부 폰트나 새 SDK 의존성은 추가하지 않았습니다.

- ROI 내부 드래그는 위치 이동, 네 변·네 모서리는 크기 변경, 이미지 안의 ROI 외부 드래그는 새 영역입니다.
  모서리/테두리의 잡기 영역이 우선합니다. 실제 이미지 밖의 여백은 조작 대상이 아닙니다.
- 내부 이동은 크기를, 리사이즈는 반대편 변/모서리를 유지합니다. 경계를 넘거나 뒤집을 수 없고
  최소 2×2px입니다. 새 영역은 어느 방향으로도 그릴 수 있으며 작은 클릭은 기존 ROI를 보존합니다.
- 원본 픽셀 좌표를 기준 상태로 사용하므로 반복 조정·창 크기 변경으로 정밀도가 누적 손실되지 않습니다.
  드래그 중 숫자와 사각형은 팝업 안에서만 즉시 갱신됩니다.
- 하단 X/Y/W/H는 정수 입력, Enter 또는 포커스 이동으로 반영합니다. 입력 중간 문자열은 반영하지 않으며
  Enter가 팝업 적용 버튼까지 실행되지 않도록 처리합니다. 범위 초과는 보정, 빈칸/문자는 이전 값 복원입니다.
- Esc·캡처 해제·창 비활성화·크기 변경은 현재 드래그만 취소합니다. Esc로 드래그를 취소해도 팝업은 남습니다.
  드래그 중이 아닐 때의 팝업 취소와 닫기는 기존 메인 ROI를 보존합니다.
- 마우스 십자선은 이미지 내 실제 위치에서 상단 X 눈금자와 왼쪽 Y 눈금자까지 연결됩니다.
  이미지 밖으로 나가면 십자선과 좌표를 숨깁니다. 레터박스가 있으면 눈금자까지의 연결 구간만 여백을 지납니다.
- 회색 그리드는 원본 좌상단 기준 100px 간격, 실제 이미지 안에만 표시합니다. 기본 켜짐이며 Material 아이콘으로
  켜고 끕니다. 선택 상태는 프로세스 메모리에만 유지하며 재실행 시 켜짐입니다. 모든 보조 표시는 출력에 포함하지 않습니다.
- `1000×720` 기본 크기와 `640×480` 최소 크기에서 숫자 입력·핸들·이미지 영역을 검사합니다.

검증 명령: `dotnet test DiffVideo.slnx -c Release`, `build/Test-DesignUi.ps1 -Mode roi`.
`roi` 모드는 실제 WPF 팝업에서 기본 그리드, 8방향 핸들, 이동/새로 그리기, 숫자 입력 이벤트,
캡처 취소/창 리사이즈, 좌표 연결선, 최소 창 크기, 세션 그리드 유지, 적용 전 모델 불변성을 확인합니다.
기존 `ui`, `features`, `checks` 회귀 검사도 유지합니다. 리소스 재측정이나 목표 기반 최적화는 하지 않습니다.

## 0.3.5 — 눈금자·타임라인 탐색·내보내기 확인

- 자르기 팝업에 원본 `(0,0)` 기준 X/Y 눈금자를 배치합니다. 100px 눈금은 유지하고
  공간이 부족하면 숫자만 200/500/1000px 등으로 줄입니다. 원본의 회전 반영 좌표를 사용합니다.
- 실제 영상 위에서는 `(x,y)`를 마우스 옆에 즉시 표시하고 이미지 밖에서는 숨깁니다.
  메인 프리뷰는 우클릭 ROI 드래그 중에만 표시합니다. 눈금·좌표는 출력되지 않습니다.
- 현재 재생 위치는 눈금자부터 영상 1/2·MP3·탐색선까지 이어지는 세로 막대입니다.
  지정 시작점은 눈금자의 별도 깃발입니다. 막대·탐색은 재생 중에는 잠깁니다.
- Material `+ / − / 전체 보기`는 2배 단계, 최대 240 DIP/초(전체 보기 배율이 더 크면
  그 배율)를 사용합니다. 현재 재생 위치를 기준으로 확대하며 전체 보기가 최소 배율입니다.
  눈금은 1/2/5/10/30/60초 등이며 1초보다 작아지지 않습니다. 편집 정밀도는 변경하지 않습니다.
- 가로 스크롤은 재생 위치를 바꾸지 않습니다. 재생 위치가 오른쪽 끝에 도달하면 다음 구간으로
  이동합니다. 사용자가 스크롤하면 자동 이동을 중지하고, 다시 재생하면 복원합니다.
- 파일명 영역은 기본 204 DIP, 최소 180 DIP, 타임라인 너비의 최대 40%입니다. 긴 이름은
  말줄임하고 툴팁으로 확장자 포함 전체 이름을 표시합니다. MP3 볼륨과 오디오 토글은 유지합니다.
- 타임라인은 내보내기 구간 조작부·글꼴 크기를 유지하기 위해 외곽 기본/최소 264 DIP,
  최대 창 높이의 50%로 조절합니다. 추가 높이는 세 트랙에 동일하게 배분합니다.
  전체 보기 중 폭을 바꾸면 자동 맞춤하며 확대 상태에서는 가능한 범위에서 초당 픽셀을 유지합니다.
  확대·패널 크기는 세션 UI 상태이며 프로젝트/설정 파일에 저장하지 않습니다.
- 내보내기 클릭 → 합성 스냅샷 → 최종 설정 확인 → 확인 버튼 → 저장 위치·파일명 선택 → 내보내기 순서입니다.
  영상별 원본 이름, 오프셋·ROI·배치·맞춤·레이어·오디오·MP3와 출력 정보를 표시합니다.
  저장 다이얼로그의 파일명 입력란에는 로컬 날짜와 UUID 앞 4자리로 만든 `YYYYMMDD-a1b2.mp4`를
  제안하며 직접 수정할 수 있습니다. 저장을 확정하기 전에는 파일을 만들지 않고, 취소하면 내보내기를
  시작하지 않습니다. 같은 이름의 파일이 있으면 기존 덮어쓰기 확인을 표시합니다.
- `파일 이름 추가하기`는 기본 해제입니다. 영상 1/2 이름을 확장자 포함 최대 두 줄로 출력하며,
  이름이 길면 말줄임합니다. 첫/마지막 프레임 유지 구간에도 표시하고 각 영상 레이어 순서를 따릅니다.
- 위치는 영상 배치 영역 상대 좌표, 앵커, 스타일, 활성화 여부로 영상별 독립 모델에 저장합니다.
  이번 버전은 왼쪽 위 고정이며 사용자 위치 입력/드래그 UI는 추후 기능입니다.
- 글꼴 설치 없이 Windows 글꼴로 Unicode 라벨 PNG를 내보내기당 한 번만 렌더링합니다.
  FFmpeg는 이를 해당 영상에 먼저 합성한 뒤 레이어를 합칩니다. 파일명은 필터 문자열에 삽입하지 않습니다.
  라벨 임시 파일은 성공·취소·실패 후 정리합니다. 출력 임시 파일은 작업별 고유 이름을 사용하여
  기존 `.part` 파일을 건드리지 않으며 원본과 같은 경로로 저장하는 것은 거부합니다.

검증: Release 경고·오류 0개, 자동 테스트 57개(장시간 스트레스 제외), 기존 WPF UI 23항목,
재생·내보내기 회귀 15항목, `Test-DesignUi.ps1 -Mode features`의 새 기능/실제 출력 검사를 실행합니다.
리소스 측정 및 목표 기반 최적화나 10분 연속 검사는 이번 변경에서 반복하지 않습니다.

## 0.3.4 — 프리뷰 우클릭 ROI와 스페이스 재생

인터뷰에서 확정한 동작을 반영했습니다.

- 영상/영상 1·2 버튼의 왼쪽 클릭으로 활성 영상을 정합니다. 우클릭은 대상을 바꾸지
  않습니다. 활성 영상 안에서 오른쪽 버튼으로 드래그하면 선택 테두리를 표시하고,
  버튼을 놓을 때 해당 영상의 ROI만 한 번 적용합니다. 재생 중에는 시작할 수 없습니다.
- 사각형은 활성 영상의 실제 그림 범위 안으로 제한합니다. Fit의 검은 여백이나 다른
  플레이어에서는 시작할 수 없습니다. Fit/Fill/늘이기, 현재 ROI와 회전 후 표시 좌표를
  고려해 원본 좌표로 변환합니다. 역방향 드래그와 경계 밖으로 나가는 드래그도 지원합니다.
- 적용 후 플레이어의 위치·배치 크기·맞춤 방식·재생 헤드·레이어 순서는 유지합니다.
  반복 드래그는 현재 보이는 영역을 추가로 자릅니다. 영상 1·2 선택 옆의 원본 복원
  아이콘으로 전체 프레임을 복구합니다. 수치 입력/별도 ROI 창은 선택적인 보조 기능입니다.
- 겹친 활성 영상은 선택 중에만 프리뷰 맨 앞으로 표시합니다. 완료·취소 시 원래 순서로
  돌아가며, 모델과 내보내기 스냅샷의 레이어 순서는 변경하지 않습니다. 드래그 중에는
  디코딩·영상 합성·ROI 모델 변경 없이 선택 테두리만 갱신합니다.
- Esc, 마우스 캡처 상실, 창 비활성화/크기 변경은 선택을 취소합니다. 단순 우클릭이나
  가로/세로 어느 한쪽이 화면상 3 DIP 미만인 작은 드래그는 ROI를 바꾸지 않습니다.
- 스페이스는 현재 위치 재생/일시정지를 전환하고 로딩 중이면 준비를 취소합니다.
  텍스트·숫자 입력, 드롭다운, 드래그 중에는 제외하며 키 자동 반복을 무시합니다.
- 타임라인 내부 높이는 234→194 DIP, 외곽 포함 약 242→202 DIP로 줄였습니다.
  40 DIP만큼 프리뷰를 늘리고 재생 버튼 40 DIP와 두 줄 트랙 정보, MP3 1ms 입력을 유지합니다.

검증: Release 빌드 경고·오류 0개, 자동 테스트 46개, WPF UI 검사 23개와 기존
재생·내보내기 회귀 검사 15개 통과. 1440×900 / 1120×720 창에서 프리뷰 높이는
각각 약 537 / 375 DIP입니다. UI 진단은 활성 대상 선택, 반복 ROI, 원본 복원,
테두리 표시, 경계 제한, 취소, 겹침 순서 복원과 스냅샷 독립성, 스페이스 입력을 포함합니다.
리소스 사용량이나 10분 연속 내보내기 스트레스 검사는 재측정하지 않았습니다.

## 0.3.3 — 프리뷰 중심 배치와 ROI 안정성

사용자의 추가 요청에 따라 `DESIGN.md`의 색상·아이콘·입력 스타일을 유지하면서
편집 공간을 넓혔습니다. 원본 디자인 문서는 변경하지 않았습니다.

- 브랜드 제목 바와 왼쪽 미디어 패널을 제거했습니다. 정보·파일 열기·내보내기·취소는
  기존 캔버스/출력 설정과 같은 한 줄에 배치합니다.
- 프리뷰 아래의 전용 재생 조작 영역을 없애고, 통합 타임라인 상단에 재생 버튼과
  현재/총 시각·시작점·상태를 함께 표시합니다.
- 파일 드래그앤드롭은 프리뷰 안에서만 받습니다. MP4/MP3를 끌어오면 안내 테두리가
  표시되며, 재생 중에는 파일 추가와 영상 블록 드래그를 받지 않습니다.
- 오른쪽 속성 패널은 216 DIP로 좁혔습니다. 영상 1/2 선택은 패널 상단,
  상세 속성은 세로 스크롤 안에 있습니다. MP3의 1ms 시작 시각 입력은 타임라인
  왼쪽 아래로 옮겼고 오디오 포함/볼륨 조작은 유지했습니다.

ROI 오류는 입력 좌표와 크기의 합이 원본 범위를 넘는 상태에서 발생했습니다.
기존에는 이 상태의 프리뷰 갱신이 실패한 뒤 재생 시작 시 검증 예외가 UI로 전파되어
앱이 종료되었습니다. ROI를 원본 표시 크기 안의 최소 2×2 영역으로 보정하고,
네 속성을 한 번에 설정한 다음 변경을 알리도록 수정했습니다. 숫자 입력 확정과
편집 창의 적용 모두 현재 재생 헤드 위치의 프리뷰를 갱신하며, 타임라인 위치나
캔버스 배치를 바꾸지 않습니다. 잘못된 설정의 재생·내보내기는 오류를 표시하고
중단하되 앱은 유지합니다. 프리뷰에서 영상 파일을 합성하는 구조로 되돌리지 않았습니다.

2026-09-04 검증: Release 빌드 경고·오류 0개, 자동 테스트 34개, 실제 WPF UI 검사
18개, 재생·내보내기 회귀 검사 15개 통과. ROI 숫자 자동 갱신, 음수/최대 정수 입력,
ROI 대화상자 적용 후 프리뷰 픽셀 변경, 적용 후 재생, 잘못된 설정의 내보내기 차단을
검사했습니다. 1440×900 / 1120×720 창에서 프리뷰 영역은 각각 약 1178×497 /
858×335 DIP였으며 바인딩 경고는 없었습니다. 리소스 재측정과 10분 연속 내보내기
스트레스 검사는 이번 UI 수정에서 다시 실행하지 않았습니다.

## 0.3.2 — Material 아이콘 중심 UI

Google 공식 Material Icons Round 24px SVG를 WPF 벡터 리소스로 포함했습니다. 파일 열기,
정보, MP4 내보내기·취소, 재생·일시정지·정지, 이전·다음 프레임, 시작점 지정,
ROI 편집·초기화·적용·취소, 레이어 순서를 아이콘으로 조작합니다. 캔버스·미디어·
프리뷰·속성·타임라인 및 시간·위치·볼륨의 짧은 라벨도 해당 아이콘으로 표시합니다.

모든 아이콘 버튼에는 한국어 툴팁과 화면 읽기 프로그램용 이름이 있으며, 비활성 버튼도
툴팁을 표시합니다. 체크박스의 체크 표시는 유지하고, 오디오는 포함/제외에 따라
스피커/음소거 아이콘으로, 비율 잠금은 잠금/해제 아이콘으로 바뀝니다.

영상 번호, 파일명, MP3 같은 포맷, 720p/1080p/4K 같은 값, 좌표·크기·시간·볼륨,
상태·오류·사용 안내 문구는 아이콘만으로 정확하게 전달할 수 없어 텍스트로 유지합니다.
Windows 기본 파일 열기·저장 대화상자의 시스템 버튼은 변경하지 않습니다.

아이콘에는 글꼴 설치나 인터넷 연결이 필요 없습니다. 원본 SVG·커밋·라이선스는
`Assets/MaterialIcons`, `THIRD-PARTY-NOTICES.md`, `licenses/MaterialIcons-LICENSE.txt`에서
확인할 수 있습니다. `Test-DesignUi.ps1`은 벡터 아이콘, 접근성 이름, 툴팁,
버튼 크기와 오디오·비율 잠금 아이콘의 상태 전환도 검사합니다.

0.3.2 검증: Release 빌드 경고·오류 0개, 자동 테스트 27개, 아이콘 UI 검사 14개,
재생·내보내기 회귀 검사 15개 통과. 리소스 재측정이나 장시간 스트레스 검사는 하지 않았습니다.

## 0.3.1 — 최초 디자인 적용 기록

아래는 최초 적용 당시의 구성입니다. 현재 배치에서는 위의 0.3.3 변경 사항이 우선합니다.
프로젝트 루트의 `DESIGN.md`를 기준으로 WPF 편집기 UI를 변경했습니다. 원본 디자인 문서는 수정하지 않았습니다.

### 적용

- 흰색 `#FFFFFF` 배경, 검은색 `#000000` 본문, 얇은 `#E6E6E6` 구분선, `#F7F7F5` 보조 표면.
- 미디어 영역 한 곳에 라일락 `#C5B0F4` 색상 블록을 사용하고 다른 영역은 흰색으로 분리합니다. 선택 상태는 검은색으로 표시합니다.
- 내보내기를 검은색 기본 버튼으로, 나머지 동작을 흰색 보조 버튼으로 구분합니다. 텍스트 버튼은 캡슐형, 프레임 버튼은 원형입니다.
- 입력 필드와 드롭다운은 8px 둥근 모서리와 포커스 테두리를 사용합니다. 큰 패널은 24px 둥근 모서리이며 그림자·그라데이션을 추가하지 않았습니다.
- 미디어 / 프리뷰 / 속성 / 타임라인을 번호와 모노스페이스 소제목으로 구분합니다. ROI 편집 창과 로딩 표시도 같은 공통 스타일을 사용합니다.
- 기존 미디어 카드 선택, 프레임 조작, 타임라인, 오디오 체크박스, ROI, 레이어 순서, 비동기 내보내기·취소를 유지합니다. MP3 시작 시각은 미디어 패널에서도 0.001초 단위로 입력할 수 있습니다.

### 데스크톱 편집기에 맞춘 조정

웹 마케팅 페이지의 64~86px 제목, 96px 섹션 간격, 모든 필드 48px 높이는 그대로 옮기지 않았습니다. 1120×720 최소 창에서 영상과 타임라인을 함께 사용할 수 있도록 제목 20~32px, 본문 12~13px, 주요 버튼 44px, 프레임 버튼 40px, 밀집 입력·보조 버튼 최소 32px를 사용합니다. 주요 간격은 8/12/16/24px입니다.

재생 조작과 시각 정보는 두 줄로 분리해 창이 작아져도 글자가 축소되지 않습니다. 미디어와 속성 패널은 세로 스크롤로 모든 항목에 접근할 수 있습니다.

독점 글꼴 figmaSans/figmaMono는 포함하지 않습니다. Windows 시스템 UI 글꼴인 Segoe UI, 한국어용 맑은 고딕, 소제목용 Consolas를 사용하므로 별도 글꼴 설치나 배포가 필요 없습니다. WPF에서 지원하지 않는 `SemiLight` 대신 `Light`를 사용합니다.

`checks` 모드는 기존 재생·일시정지·정지·시작점·드래그 확정·내보내기 취소 회귀 검사를 실행합니다. 두 모드 모두 리소스 성능 측정이나 목표 기반 최적화는 하지 않습니다.
