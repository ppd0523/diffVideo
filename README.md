# DiffVideo

DiffVideo는 Windows 11에서 MP4 영상 두 개와 선택적인 MP3 음원을 하나의
H.264/AAC MP4로 합성하는 portable WPF 애플리케이션입니다.

확정 사양과 수용 기준은 [구현 계획](docs/IMPLEMENTATION-PLAN.md)에 정리되어 있습니다.

## 주요 기능

- MP4 두 개와 MP3 한 개 드래그앤드롭
- 사용자 지정 캔버스(최대 3840×2160)와 24/25/30/50/60fps
- 활성 영상의 프리뷰 우클릭 드래그로 고정 ROI 지정·원본 복원, Fit/Fill/늘이기, 비율 잠금, 레이어 순서
- ROI 팝업의 사각형 이동·8방향 크기 조절·외부 드래그로 새 영역 선택, X/Y/W/H 숫자 정밀 조정
- ROI 팝업의 눈금자 연결 십자선과 회색 100px 그리드 켜기/끄기
- 독립적인 영상·MP3 시작 시각과 사용자 지정 출력 종료 시각
- 재생·일시정지·정지, 지정 재생 시작점, 1프레임 단위 탐색
- 100px 원본 눈금자와 마우스 옆 좌표, 확대·축소·전체 보기와 가로 스크롤 타임라인
- 타임라인 전체를 관통하는 재생 위치 막대, 파일명 고정 영역과 타임라인 높이 조절
- 통합 타임라인의 내보내기 시작·종료 지정, 드래그 경계, 전체 구간 복원
- 개별 영상 플레이어 기반 프리뷰: ROI·위치·크기는 화면 표시로 처리하고 영상 합성은 내보내기 때만 수행
- 드래그 중 최대 초당 10회 원본 프레임 탐색과 드롭 시 한 번만 적용되는 타임라인 편집
- 영상 시작 전 첫 프레임, 종료 후 마지막 프레임 유지
- 영상별 오디오 포함 여부와 0~200% 볼륨, MP3 기본 30%
- 48kHz 스테레오 믹싱과 항상 활성화되는 클리핑 방지 리미터
- 타임라인 재생 중 내보내기와 같은 오디오 믹스 미리듣기
- 공통 오디오 시계에 맞춘 영상 동기화와 재생 준비 중 로딩 표시
- HDR 입력의 SDR BT.709 변환, 회전 메타데이터 적용
- AMD AMF 인코딩 후 Media Foundation 자동 대체
- 편집·재생과 독립적으로 진행되고 취소 가능한 스냅샷 기반 `.part` 내보내기
- 내보내기 최종 설정 확인 및 영상별 파일명 표시 옵션(최대 두 줄, 기본 해제)

프로젝트 저장, ROI 키프레임, 자동 피사체 추적, HDR 출력 및 MP3 반복은
지원하지 않습니다.

## 사용

1. portable ZIP을 원하는 폴더에 풉니다.
2. `DiffVideo.exe`를 실행합니다.
3. MP4 두 개와 필요한 경우 MP3 한 개를 **프리뷰 영역**에 끌어 놓거나 폴더 아이콘으로 엽니다.
4. 프리뷰의 영상 또는 오른쪽 영상 1/2 버튼을 **클릭해 활성화**합니다.
   오른쪽 상단 **위에 표시**에서 **A · 영상 1** 또는 **B · 영상 2**를 선택하면
   겹치는 부분에서 어느 영상이 앞에 보일지 정할 수 있습니다. 프리뷰와 내보내기에 동일하게 적용됩니다.
   정지·일시정지 상태에서 영상 내부를 왼쪽 드래그하면 배치가 이동하고,
   네 변·네 모서리를 드래그하면 크기가 바뀝니다. 선택한 영상에는 8개 핸들이 표시됩니다.
   비율 잠금 시 기존 ROI 비율을 유지하며, 해제 시 가로세로를 자유롭게 조절합니다.
   음수 X/Y를 포함한 화면 밖 배치를 허용하며, 벗어난 부분은 프리뷰와 내보내기에서 잘립니다.
   화면 밖으로 완전히 이동한 영상은 오른쪽 영상 1/2 선택과 X/Y 숫자 입력으로 되돌릴 수 있습니다.
   Esc·마우스 캡처 해제·창 크기 변경은 드래그 이전 배치를 복원합니다.
   정지·일시정지
   상태에서 활성 영상 위에 **오른쪽 마우스 버튼을 누른 채 사각형을 드래그**하고 놓으면
   ROI가 적용됩니다. 사각형은 활성 영상의 실제 그림 범위 안으로 제한되며, 플레이어의
   위치와 배치 크기는 유지됩니다. 다시 드래그하면 현재 보이는 부분을 추가로 자릅니다.
   영상 1/2 버튼 옆의 **원본 복원** 아이콘으로 전체 프레임으로 되돌릴 수 있습니다.
   `Esc`는 선택을 취소합니다. 숫자 입력과 별도 ROI 편집 창도 보조 기능으로 남아 있습니다.
   자르기 창의 눈금은 원본 좌상단 `(0,0)` 기준 100px 간격입니다. 작은 화면에서는
   숫자만 간소화합니다. 마우스 옆 `(x,y)` 좌표는 실제 영상 위에서만 표시되며,
   메인 프리뷰에서는 오른쪽 버튼으로 ROI를 드래그하는 동안에만 표시됩니다.
   별도 ROI 팝업에서는 왼쪽 버튼으로 사각형 내부를 드래그하면 이동하고, 네 변·네 모서리를
   드래그하면 크기가 바뀝니다. 실제 이미지 안의 사각형 외부를 드래그하면 새 ROI를 그립니다.
   전체 프레임이 선택된 경우 먼저 핸들로 크기를 줄여 외부 공간을 만들 수 있습니다.
   하단 X/Y/W/H는 원본 픽셀 기준 정수이며 Enter 또는 포커스 이동 시 반영됩니다.
   X/Y 변경은 크기를 유지하고, W/H 변경은 좌상단을 유지합니다. 이미지 경계를 넘으면
   보정하고 최소 크기는 2×2px입니다. 빈칸·잘못된 입력은 이전 값으로 복원합니다.
   드래그 중 Esc·마우스 캡처 해제·창 크기 변경은 해당 드래그 직전 상태로 되돌립니다.
   팝업의 적용 버튼을 눌러야 메인 ROI가 바뀌며, 취소·닫기는 기존 ROI를 유지합니다.
   마우스 십자선은 상단·왼쪽 눈금자까지 이어집니다. 그리드 버튼은 기본 켜짐이고
   같은 앱 실행 중에는 선택 상태를 유지합니다. 재실행하면 켜짐으로 시작합니다.
   눈금·좌표·십자선·그리드는 내보낸 영상에 포함하지 않습니다.
5. 재생 조작과 현재/총 시각은 통합 타임라인 상단에 있습니다. 재생 위치에서
   **시작점 지정**(깃발)을 누르면 이후 정지는 그 위치로 돌아갑니다.
   MP3 시작 시각은 타임라인 왼쪽 아래에서 0.001초 단위로 입력할 수 있습니다.
   **스페이스 키**는 현재 위치에서 재생/일시정지를 전환합니다. 로딩 중 누르면 재생
   준비를 취소합니다. 입력란·드롭다운 조작 중이나 드래그 중에는 단축키가 작동하지
   않으며, 길게 눌러도 한 번만 전환합니다.
   `+ / − / 전체 보기`로 타임라인 표시 배율을 바꿉니다. 세로 막대는 현재 재생 위치,
   깃발은 정지 시 돌아갈 시작점입니다. 타임라인 위 경계를 위아래로, 왼쪽 파일명
   영역의 경계를 좌우로 드래그하면 크기가 바뀝니다. 재생 중에는 자동으로 다음
   구간을 표시하고, 가로 스크롤을 직접 조작하면 자동 이동을 멈춥니다. 일시정지 후
   재생하면 자동 이동이 다시 켜집니다. 이 화면 설정은 앱을 종료하면 초기화됩니다.
6. 통합 타임라인의 **내보내기 구간**에서 저장할 시작·종료를 정합니다.
   기본값은 **0초부터 전체 종료까지**입니다. 현재 재생 위치로 이동한 뒤 **현재 → 시작**,
   **현재 → 종료**를 누르거나 눈금 위의 갈색 `[` / `]` 경계를 드래그합니다.
   초 단위 숫자 입력도 가능하며 출력 FPS의 프레임 경계에 맞춰집니다.
   종료는 저장에서 제외되는 경계입니다. 예를 들어 5~12초를 선택하면 5초부터 12초 직전까지
   7초를 저장하며, 영상과 MP3를 포함한 모든 오디오에 같은 구간을 적용합니다.
   경계는 서로 교차하지 않고 최소 한 프레임을 유지합니다. 드래그 중 Esc로 이전 구간을 복원합니다.
   **전체 구간**을 누르면 기본값으로 돌아가며 전체 종료 시각 변경을 따라갑니다.
   구간 지정은 정지·일시정지 상태에서 가능하며, 기존 재생 시작점과 트랙 시작 시각은 유지합니다.
   상단의 **MP4 내보내기** 아이콘을 선택하고 구간·저장 길이를 포함한 최종 설정을 확인합니다.
   **파일 이름 추가하기**를 체크하면 두 영상의 확장자 포함 파일명을 각 영상 왼쪽 위에
   흰 글자와 반투명 검은 배경으로 넣습니다. 최대 두 줄이고 긴 이름은 말줄임 처리합니다.
   MP3 이름과 폴더 경로는 넣지 않습니다. 영상에 직접 그려지므로 저장 후 제거할 수 없습니다.
   **확인**을 누르면 저장 다이얼로그가 열립니다. 저장 위치를 고르고 파일 이름을 직접 입력할 수 있습니다.
   기본 파일명은 오늘 날짜와 UUID 앞 4자리로 만든 `YYYYMMDD-a1b2.mp4` 형식이며 자유롭게 변경할 수 있습니다.
   **저장**을 누르면 처음 내보내기 버튼을 클릭한 시점의 설정으로 내보냅니다. 저장 다이얼로그에서
   취소하면 내보내기를 시작하지 않으며, 같은 이름의 파일이 있으면 덮어쓸지 확인합니다.
   진행 중에도 재생과 다른 편집을 계속할 수 있습니다. 상단 취소 아이콘으로 중단할 수 있습니다.

별도의 설치, 관리자 권한 또는 .NET 런타임 설치가 필요하지 않습니다.
Windows 플레이어가 원본 코덱을 열지 못하면 포함된 FFmpeg로 해당 원본만
디코딩합니다. 프리뷰의 색감·HDR 밝기·세부 화질은 최종 출력과 다를 수 있습니다.

프리뷰 구조와 검증 방법은 [프리뷰 설계](docs/PREVIEW-ARCHITECTURE.md)에 있습니다.
[리소스 비교 결과](docs/RESOURCE-COMPARISON.md)는 감소 목표 없이 관찰한 수치입니다.
[UI 디자인 적용](docs/UI-DESIGN.md)은 `DESIGN.md`의 흑백·라일락 스타일을
데스크톱 편집기에 반영한 내용과 화면 검증 방법을 설명합니다.

## 개발 환경

- Windows 11 x64
- .NET SDK 10.0.400 이상(10.0 기능 대역)
- PowerShell 7 또는 Windows PowerShell 5.1

```powershell
.\build\Get-FFmpeg.ps1
$env:DIFFVIDEO_FFMPEG_BIN = "$PWD\tools\ffmpeg\bin"
dotnet test .\DiffVideo.slnx
.\build\Publish-Portable.ps1
```

결과는 `artifacts/DiffVideo-win-x64-portable.zip`에 생성됩니다.

이름 변경 후 첫 버전은 0.4.0입니다. 버전별 배포는
`./build/Publish-Portable.ps1 -PackageName DiffVideo-0.4.0-win-x64`로 생성할 수 있습니다.
작업 폴더 이름은 바꿀 필요가 없으며, 이전 제품명으로 만든 배포본은 덮어쓰지 않습니다.
